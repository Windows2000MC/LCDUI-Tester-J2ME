# LCDUI Tester J2ME
LCDUI Tester is a java application that test the java user interface and graphics. Supports on MIDP-2.0 | CLDC-1.1 enabled java phones.

# How it works?

It's tests each element on screen which can be found on javax.microedition.lcdui.* like Gauge, ChoiceGroup, List etc. Other than testing High-level UI. I also provided low-level Canvas and Graphics demos with FPS counter to check your java phone's performance.

# Development phase

The application is developed entirely on Symphony D54+ java phone. Thanks to J2ME SDK Mobile and PaintCAD J2ME, The application is written, compiled, tested entirely on java phone for ensuring the best experience and compatibility on other java enabled phones

# Features

1. Lists of High level UI, Canvas and Graphics are shown in Menu
2. Has Graphics Demos with FPS counter for testing raw performance
3. Each element shows some info about this element and how to use it
4. First java application that has a graphical splash screen
5. Has a fallback feature if icons on List and ChoiceGroup failed to load

# Graphics Demos

1. 3D Cube [No M3G Support] - This demo shows a 3D looking spinning cube on black screen with FPS counter. The demo was generated by Google Gemini and it was designed for budget friendly java phones that doesn't has M3G (Mobile 3D Graphics) API and it's optimized for running on slow or mid-range chipset. But needs CLDC 1.1 to run the floating point calculation.

Performance result 

Symphony D54+ [MediaTek MT6260] - 20 to 21 FPS

J2ME Loader on Oppo A18 [Helio G85] - 33 FPS

[Note - The FPS is capped to 30 FPS max]
