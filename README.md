# LCDUI Tester J2ME
LCDUI Tester is a java application that test the java user interface and graphics. Supports on MIDP-2.0 and CLDC-1.1 enabled java phones.

# How it works?

It's tests each element on screen which can be found on javax.microedition.lcdui.* like Gauge, ChoiceGroup, List etc. Other than testing High-level UI. I also provided low-level Canvas and Graphics demos with FPS counter to check your java phone's performance.
